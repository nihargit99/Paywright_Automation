## OOPS in typescript

When ever we need to store the dat and when we access that, we need to follow certain rules, that is know as OOPs concept.

1. Class
2. Object
3. Constructor
4. Inheritance
5. Polymorphism
6. Abstraction
7. Interface
8. Encapsulation
9. Static
10. Abstract
11. this and super
12. Access modifier: (public, private, protected)

## Class
Class is a data type or template that is going to provide a structured way to define all the data, methods and objects together in one place.

## Object
Object is a new instance of the class. (New Xerox copy/subset of the class. )

## Constructor
Constructor is a default method created by TypeScript every time we are going to create a new class. The constructor is going to initialize all the properties of the class whenever we are going to create an object.
