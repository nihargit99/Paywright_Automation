1. Project folder Naming convention(Root Folder)

    Convention: kebab-case(All characters are lowercase + hyphen)
        e.g.- java-script-training
    
2. Sub-folder Naming convention

    Convention: kebab-case(All characters are lowercase + hyphen)
        e.g.- java-script-training

    pagemethods- camelcase: starting with lowercase then uppercase 
        e,g.- javaScript

3. JS/TS File Naming convention

    Convention: kebab-case
    e.g.- first-js-program.js
    e.g.-first-ts-program.ts
